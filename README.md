# Mod App Filter

เว็บต้นแบบสำหรับปกปิดข้อมูลส่วนบุคคลก่อนส่งต่อให้ AI หรือระบบอื่นภายในองค์กร

## เริ่มต้น

ต้องใช้ Node.js 20.9 ขึ้นไป

```sh
npm install
npm run dev
```

เปิด http://localhost:3000 จากโฟลเดอร์หลัก `Mod App Filter` ได้เลย บน PowerShell ที่ปิดการรันสคริปต์ ให้ใช้ `npm.cmd` แทน `npm`

## เทคโนโลยี

Next.js App Router, TypeScript, Tailwind CSS v4 และ shadcn/ui (Button, Switch, Dialog บน Radix UI)

## ฟีเจอร์ที่ลองได้

- วางข้อความและอัปโหลดไฟล์ TXT, CSV, JSON, Markdown แบบ UTF-8 ขนาดไม่เกิน 5 MB
- ปกปิดชื่อที่มีป้ายกำกับหรือคำนำหน้า เลขบัตรประชาชน อีเมล เบอร์โทรไทย และคำที่กำหนดเอง
- เลือกปกปิดทั้งหมด เหลือท้าย 3 ตัวอักษร หรือแทนด้วยประเภท
- ดูผลลัพธ์ คัดลอก และดาวน์โหลดกลับเป็นไฟล์ชนิดเดิม
- ตั้งค่านโยบายและดูประวัติในหน่วยความจำของแท็บปัจจุบัน
- หน้าเอกสาร API และตั้งค่าการเชื่อมต่อ Supabase แบบต้นแบบ

ข้อมูลประมวลผลในเบราว์เซอร์ ไม่บันทึกเนื้อหาลง localStorage หรือฐานข้อมูล และประวัติหายเมื่อรีเฟรช

## ขอบเขตของต้นแบบ

ยังไม่เชื่อม Supabase, ระบบสมาชิก/สิทธิ์, API จริง, OCR, PDF หรือ DOCX การตรวจจับใช้กฎ ไม่ใช่ NER ชื่อที่ไม่มีป้ายกำกับอาจตรวจไม่พบ ต้องตรวจผลลัพธ์ก่อนส่งต่อ การซ่อนบางส่วนยังเหลือข้อมูลท้ายตามรูปแบบที่เลือก ไฟล์ JSON/CSV จะปกปิดจากข้อความดิบโดยรักษาเครื่องหมายคั่นไว้ ควรตรวจสอบโครงสร้างและความหมายก่อนใช้งานจริง

ชื่อ API host และ API key ในหน้าคู่มือเป็น placeholder ไม่ใช่บริการที่เปิดใช้งานแล้ว

เตรียมเชื่อม Supabase ภายหลัง: Auth + organization membership, masking policies, metadata-only audit events และ API keys แบบ hash พร้อม RLS โดยไม่เก็บข้อมูลต้นฉบับเป็นค่าเริ่มต้น

## ตรวจสอบ

```sh
npm run test
npm run typecheck
npm run build
```

โหมดปัจจุบันใช้ static export (`out/`) เพื่อพรีวิว UI เมื่อเพิ่ม Backend ให้ปรับ `next.config.ts` และเพิ่ม authentication ก่อนเปิดใช้ API
